# Safety and Security Notes

This repository is a research prototype for intervention-policy evaluation. It is **not** a production authorization layer and should not be used to execute consequential real-world actions without an independent permission and safety system.

High-stakes, irreversible, financial, privacy-sensitive, or safety-sensitive actions should default to preserving user control. Synthetic labels in GrantShiftBench are not a substitute for legal, policy, safety, or domain-specific review.
