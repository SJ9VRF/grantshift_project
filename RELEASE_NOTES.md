# GrantShift v1.7.0

This release focuses on evidence integrity rather than adding another synthetic benchmark layer. It adds a claim-to-experiment-to-artifact evidence graph, one-command core reproduction, public-number consistency checks, and a skeptical reviewer red-team. Every registered claim now links to at least one journal experiment and existing raw evidence. The core capability and mutation experiments were rerun in this release. No frontier-model, human-validity, production-safety, or post-training-improvement claim is added.
