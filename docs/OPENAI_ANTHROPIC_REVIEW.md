# Frontier-lab relevance review — 25 September 2026

This document is a project-positioning audit, not an endorsement claim.

## OpenAI fit

Current OpenAI agent/post-training roles emphasize end-to-end ownership across environments, graders, reward signals, evals, diagnostics, synthetic data, failure mining, reproducibility, and production-like agent harnesses. Personal AGI roles additionally emphasize personalization, memory, proactivity, dataset creation, evaluations, and RL/post-training.

GrantShift maps to that research shape through: matched behavioral hypotheses; executable transition environments; outcome and authorization graders; repeated-trial reliability; incident mining; chosen/rejected training-record export; claim-evidence gating; and provider-neutral frontier-eval harnesses.

The missing high-value evidence is also explicit: the release has not executed frontier model A/B post-training, real product integrations, or human-calibrated authorization judgments.

## Anthropic fit

Anthropic's published agent-evaluation guidance emphasizes multi-turn trajectories, tool/state changes, environment outcomes, repeated trials, and separating agent behavior from harness assumptions. Current research-engineering openings include Computer Use, Model Evaluations, RL, Production Model Post-Training, Environments/Universe-style work, and research infrastructure across New York/San Francisco/Seattle depending on role.

GrantShift's strongest alignment is therefore not the hand-written policy itself; it is the evaluation design that makes a hidden harness/model shortcut falsifiable. v1.2 is specifically structured so that a latest-label policy can pass the easy suite and fail a scope-bound adversarial suite.

## Hiring-manager signal

The repository should be read as evidence of this workflow:

**ambiguous model behavior → formal variable separation → controlled benchmark → adversarial falsification → trajectory/environment grading → statistical uncertainty → failure mining → training-data interface → reproducible release → explicit evidence boundary.**

That is a stronger signal than a polished demo with a single headline accuracy number.
