# Project Summary

## Homepage card

### When Should AI Act?
**Learning the Personalized Intervention Frontier for AI Agents**

A research system for deciding when a personal AI should **act, ask, suggest, remind, wait, defer, or stay silent**. It combines user-specific autonomy preferences, risk and reversibility, intent/execution uncertainty, preference drift, and evaluation that explicitly measures false proactivity and missed opportunities.

**Artifacts:** Paper · GrantShiftBench · GitHub · Eval Dashboard · Decision Trace · Failure Analysis

## One-line résumé version
Built GrantShiftBench and an end-to-end personalized proactivity research stack spanning intervention-policy learning, held-out calibration, pairwise preference modeling, longitudinal preference drift, safety/autonomy metrics, ablations, and reproducible eval infrastructure.

## Research identity version
I study not only whether agents can complete tasks, but whether they can exercise calibrated judgment about **when their involvement is warranted at all**—especially under uncertainty, changing user preferences, and asymmetric autonomy costs.
