# Paper readiness matrix

## Ready in this archive
- Clear hypothesis: preference and permission are distinct behavioral variables.
- 6,000-case natural-language factorial pilot with grouped counterfactual splits.
- Input/gold separation that removes direct structured latent-feature exposure.
- C0-C3 causal-information ablations.
- Always-ask / always-silent / always-act / always-suggest baselines.
- Unauthorized-action, question-burden, unnecessary-intervention, missed-opportunity, and configurable utility metrics.
- Consequence and irreversibility simulator.
- 100-turn preference-drift evaluation.
- Human-study protocol, annotation schema, blinded items, and power-analysis tooling.
- Frontier-model prompt export and scoring harness.
- Croissant metadata and dataset card.
- Rewritten paper with bounded claims and explicit limitations.
- Reproducible package, tests, CI-oriented commands, release audit, and PDF.

## Requires external empirical access before a strong conference submission can make the corresponding claim
- Human participants / ethics review -> human gold labels, agreement, individual-level personalization evidence.
- Frontier-model APIs or weights -> contemporary model-family comparison and scale analysis.
- External benchmark access/licensing -> KnowU/ProAgent/realistic-task counterfactual audit.
- Real tool sandbox / deployment -> downstream consequence and longitudinal interaction evidence.

These rows are intentionally not filled with simulated or fabricated results.
