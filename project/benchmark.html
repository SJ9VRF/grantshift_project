GrantShiftBench

Capability-Lifecycle Challenge

A controlled synthetic benchmark for testing whether an agent keeps authorization bound to the right principal, request, resource, revision, nonce, expiry, revocation history, and delegation chain.

What it tests

  • direct nonce revocation
  • parent-delegation revocation
  • concurrent confirmation reordering
  • principal mismatch
  • request changes after grant
  • resource mismatch
  • revision mismatch
  • principal switch with stale nonce
  • scope change followed by fresh grant

Mutation sensitivity

Evaluation philosophy

GrantShift separates task utility from authorization validity. A tool call can produce the intended external outcome and still be a failure if the capability used to authorize it is stale or invalid.
