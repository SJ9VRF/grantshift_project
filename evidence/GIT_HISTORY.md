# Git History Policy

GrantShift was developed before a trustworthy public Git history was preserved. We do **not** backdate or fabricate that history.

The repository therefore starts with one explicitly labeled import commit:

`import: GrantShift v1.5.0 research snapshot`

From that point forward, changes are committed incrementally. The Evidence Layer itself is split into separate commits for raw evidence organization, research journal/decision records, and homepage integration. Commit timestamps are the actual local Git timestamps produced during this work; no historical dates were invented.
