# Evidence Layer

The polished homepage answers “what is GrantShift?” This directory answers “what actually happened while building it?”

- `EXPERIMENT_JOURNAL.md` — hypothesis → setup → result → interpretation → next decision.
- `FAILED_EXPERIMENTS.md` — negative results and broken designs retained on purpose.
- `DECISION_LOG.md` — decisions, alternatives, evidence, trade-offs and outcomes.
- `REAL_EVAL_TABLES.md` — executed evaluation tables with evidence boundaries.
- `UNEXPECTED_FINDINGS.md` — findings that changed the research direction.
- `GIT_HISTORY.md` — honest repository-history policy and current incremental commits.

Raw evidence lives under `artifacts/experiment_logs/`, `artifacts/eval_runs/`, `artifacts/failure_examples/`, `artifacts/plots/`, `artifacts/configs/`, `artifacts/qualitative_cases/`, and `artifacts/ablations/`.
